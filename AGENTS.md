# Instrukcje dla agentów spoza Claude (np. Codex, GPT)

Repo istoty: osobisty asystent, prototyp „JARVIS HYBRID 0.1” od GPT. Zasady są w `CLAUDE.md`, proces w `PROCES.md` (nadrzędny). Obowiązują Cię tak samo.

**Start każdej sesji:** `git pull`, `STAN.md`, `SKRZYNKA.md`, `USTALENIA.md`. Każda odpowiedź zaczyna się linią `RRRR-MM-DD GG:MM:SS · temat` z czasem odczytanym, nie szacowanym. Zanim użyjesz czegokolwiek, co istnieje, sprawdź w `ARTEFAKTY.md`, która wersja `obowiązuje`.

Procedury, które Claude ma jako skille w `.claude/skills/`, czytaj jak zwykłe pliki i stosuj: `dziennik`, `koniec-tury`, `nowy-skill`, `zmiana-granicy`.

Granic autonomii istoty (`PROCES.md` §6) nie zmieniasz bez „tak” autora na konkretną propozycję.
